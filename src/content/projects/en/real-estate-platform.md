## Overview

Web platform for the real estate market, developed as a university thesis project. Includes property management, geographic visualization, and recommendation features.

## Problem

Creating a platform that combines property listings with geographic data and intelligent recommendations to help users find properties that match their preferences.

## Solution

Built a full-stack application with Node.js backend, React frontend, MongoDB for data storage, and Python-based machine learning for property recommendations.

## Main Features

- Property listings and management
- Geographic visualization with maps
- Machine learning-based recommendations
- Search and filtering
- User authentication
- Responsive design
