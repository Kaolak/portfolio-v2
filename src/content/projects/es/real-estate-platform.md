## Descripción general

Plataforma web para el mercado inmobiliario, desarrollada como proyecto de tesis universitaria. Incluye gestión de propiedades, visualización geográfica y funcionalidades de recomendación.

## Problema

Crear una plataforma que combine publicaciones de propiedades con datos geográficos y recomendaciones inteligentes para ayudar a los usuarios a encontrar propiedades que se ajusten a sus preferencias.

## Solución

Desarrollé una aplicación full stack con backend en Node.js, frontend en React, MongoDB para el almacenamiento de datos y machine learning en Python para las recomendaciones de propiedades.

## Funcionalidades principales

- Publicación y gestión de propiedades
- Visualización geográfica con mapas
- Recomendaciones basadas en machine learning
- Búsqueda y filtrado
- Autenticación de usuarios
- Diseño responsive
