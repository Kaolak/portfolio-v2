## Descripción general

Sistema empresarial diseñado para gestionar procesos y operaciones institucionales. Desarrollado como parte de mi experiencia profesional, con foco en el desarrollo backend y el diseño de APIs.

## Problema

La organización necesitaba un sistema confiable para gestionar flujos de trabajo complejos que involucraban múltiples roles de usuario, procesamiento de datos e integración con herramientas existentes.

## Solución

Desarrollé servicios backend con Java y Spring Boot, diseñé APIs REST, implementé mecanismos de autenticación y autorización y colaboré con el equipo de frontend para la integración.

## Mi aportación

- Desarrollo de funcionalidades backend
- Diseño e implementación de APIs
- Integración y optimización de base de datos
- Implementación de autenticación y autorización
- Automatización de DevOps
- Colaboración con frontend

## Tecnologías

Java · Spring Boot · SQL · React · AWS · Docker · Git
